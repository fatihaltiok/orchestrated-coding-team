# results/ — computed figures, written down as the paper prints them

Every file here is generated by `make results` (= `python3 scripts/make_results.py`)
from the raw data in `data/`. Only values a script computes end up here: counting
a one-by-one listing, averaging over runs, a share, rounding to the printed
precision. Nothing in these files is typed in by hand and no typed-in JSON
counter is copied — a test rebuilds everything into a temporary directory and
compares byte for byte (`scripts/tests/test_results.py`), and every value must
sit in a `numbers.csv` row with method `script:` and the same value.

Columns: `id` (the `numbers.csv` row), `quantity` (short English name),
`value_as_in_paper` (exactly as the paper prints it), `value_raw` (unrounded),
`inputs` (the `data/` files read), `command` (the exact command that prints
that row's value).

The `recorded` numbers of `numbers.csv` are deliberately **not** here: their raw
data was never kept and only dated excerpts of the project log exist (see
`data/recorded/`). Nothing is recomputed or made up for them.
